# Archived versions

These files are retained for reference and are not the primary launch targets.

- `main_previous.cpp.txt`: previous firmware snapshot (`src/main copy.cpp.txt`).
- `ground_station_original.py`: original ground-station script.
- `ground_station_v2.py`: earlier v2 interface.
- `ground_station_v2_3d_ui.py`: earlier 3D interface.

`src/main copy2.cpp.txt` was byte-for-byte identical to the current `src/main.cpp` in the supplied ZIP, so the redundant duplicate was not copied.
